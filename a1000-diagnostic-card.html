Before you start

6 checks

Isolate power and let the boilers cool before opening panels, then run the five-minute check below before replacing parts or clearing codes. Most A1000 callbacks are a missing part, a water problem or an overdue clean, not a failed component.

Safety

  • Lock out and tag the supply. The machine is a high-load unit: 220-240 V single phase draws 5590-7920 W on a 30 A fuse, and the 2-line 60 Hz version 4500-5300 W on 16 A. Confirm the data plate at each site.
  • Hot liquid and steam leave the spouts during cleaning and rinsing. Keep hands clear of spouts and nozzles.
  • The powder hopper worm gear can cut or crush. Take care when cleaning it.
  • Boiler faults trip at over 150 °C (or 25 °C over setpoint), so treat any heating code as a hot-part job.

Check first, every call (about 5 minutes)

  1. Read the screen. Note the code, the message and the colour (yellow, orange or red edge light). Tap the symbol for the on-screen instructions. Event messages are not shown on screen, only logged, so pull the error history before you restart.
  2. Record the hardware and software versions: tap the Franke logo, enter the PIN, then menu 0.10 System information.
  3. Look for a missing or unlocked part. Codes 425-431 and 461 flag a missing or badly seated brewing unit, internal water tank, grounds container, drip tray or bean/powder hopper, or an open grounds door.
  4. Check water: tap open, no leaks, filter not used up (code 602). Reverse-osmosis water needs at least 30-50 ppm dissolved solids or the boiler can overfill.
  5. Check clearances: 50 mm at the rear, 200 mm above, 100 mm to the right. Blocked clearance lets heat build up and cause faults.
  6. Restart once. Most hardware messages say to restart the system. If the same code returns, go to its table below.

Brewing unit

8 codes

Most brewing unit codes come down to the chamber not travelling the full distance, so check the incremental sensor, the motor and whether the unit is dirty before replacing anything.

Code Meaning What to do
009-013 Motor timeout: too few increments counted while the chamber moved Restart. Check the incremental sensor and the motor. Clean the brewing unit with a brush.
014 Incremental sensor: more than one negative increment, chamber moving the wrong way Check the incremental sensor wiring, then as for 009-013.
015 Motor timeout during cleaning Restart, then repeat the cleaning cycle.
027 Brewing unit locking mechanism: unit not locked The guide lists no steps. Reseat the unit so it locks.
028 Brewing unit missing The guide lists no steps. Fit and lock the brewing unit.
030 Error while recalibrating the brewing unit at start-up Restart. Check the incremental sensor and motor. Clean the unit with a brush.
048 Brew cancelled: chamber opened too far Select a new drink (this recalibrates). If it repeats, check the values in menu 5.2 Brewing unit.
049 Chamber could not close Select a new drink. Check the grind quantity and the grinder calibration (Grinder 1-3).

Fluid system

Heating system

8 codes

Heating codes repeat the same pattern for each boiler, so learn the fault type once and read the code to find which heater it is.

Fault type Codes What it means What to do
Sensor short circuit 501 (steam) 509 (brew) 517 (thermoblock) 544 (hot water) NTC temperature sensor shorted Restart. Check the NTC and replace if needed. Check the sensor cable and plug.
Sensor open or missing 502 (steam) 510 (brew) 518 (thermoblock) 545 (hot water) NTC missing or interrupted Same as above.
No temperature rise 503 (steam) 511 (brew) 519 (thermoblock) 546 (hot water) Less than 2 °C rise in 60 s while heating (3 °C for the thermoblock) Restart. Check the electrical circuit, the Klixon, the NTC, the heating element and the connections.
Over-temperature 504 (steam) 512 (brew) 547 (hot water) 520 (thermoblock) Above 150 °C or 25 °C over the setpoint (thermoblock: 15 °C over) Same checks as for no temperature rise.
Heater on too long 505 (steam) 513 (brew) 548 (hot water) 521 (thermoblock) Heater time-out Same checks as for no temperature rise.
Slow to reach setpoint 507 (steam) 515 (brew) 549 (hot water) 523 (thermoblock) Element on continuously for 3 min (steam, thermoblock) or 6 min (brew, hot water). Products blocked. Wait. The message clears when the setpoint is reached. If it keeps returning, treat it as a no-temperature-rise fault.
Steam boiler pressure sensor 538 (short) 539 (missing or open) Pressure sensor fault on H2 Restart. Check the sensor and its connections.
Heater input/output/surface sensors 585-590 591-593 594-595 597 599 Sensor faults, temperature rise too low, over-temperature, heater timeout, deviation, failed H1 or H2 check The guide lists no steps. Use the heating test menu and the same checks as above.

Heater numbering varies. The guide calls heater 2 the steam boiler in the 5xx codes but the hot-water boiler in the 06x fill codes. Confirm against the wiring diagram on the machine in front of you. The guide's lists also say “check heating element 2” under boiler 1 and 3 codes, which looks like a copy-over: test the element for the heater the code names.

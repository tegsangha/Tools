Date and time source

The code uses the date and time shown on the machine's operator panel. If the panel clock differs from this device, switch to Match panel and enter what the panel shows.

Steps on the machine
  1. Tap the Franke logo at the top left of the monitor. If nobody is logged in, tap it twice, then sign in with a user login.
  2. Enter the code above as the PIN for the maintenance level.
  3. Open the Service Menu.
Check against the manual

The manual's example date is 28.09.2012 at 11:35 and its PIN reads 37*2012*47. Day + Month = 37 and the year is 2012. Hour + Minute adds up to 46 here, so the last number on that line may be a misprint or a different rule. If the machine rejects the code, compare the last number first.
